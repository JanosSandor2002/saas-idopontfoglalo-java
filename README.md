# idopontfoglalo

A Spring Boot backend for an appointment booking system. The exact domain/use case (e.g. salon, clinic, general-purpose booking) is not finalized yet — the project currently focuses on building out the core booking functionality and architecture.

> **Status: early stage / WIP.** The project is in its earliest phase — entities and core setup are still being defined.

## Tech Stack

- **Language:** Java
- **Framework:** Spring Boot
- **Database:** PostgreSQL
- **Environment/config management:** `.env` + Docker Compose (planned)

## Current Progress
